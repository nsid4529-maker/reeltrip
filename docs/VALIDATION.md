# Evidence and limits

As of 25 November 2026:

- The published web prototype was exercised through fresh source submission, analysis and real Google map rendering.
- On the latest two checks, rendered markers were observed by 58.077 seconds for a TikTok and 38.355 seconds for a previously failing Instagram reel. These are single-run upper bounds including observation delay, with some warm venue matches—not p95 results or guarantees. Earlier runs took longer or failed.
- The latest development checkpoint passed 557 web tests, TypeScript checks, 109 worker tests and 25 native core tests. The sanitized public snapshot separately passed all 557 web tests and TypeScript checks using the existing installed dependencies; a clean dependency install and fresh worker/native runs were not repeated.
- The founder confirmed that the updated Instagram share screen opens on a physical iPhone. All save destinations and native TikTok sharing were not separately observed end-to-end.
- The planned real-group trial has not happened. Simulated run-throughs and technical reel samples are not customers or product-market fit.
- The full 20-reel acceptance corpus was not rerun after the final corrections. Some extracted places remain unmatched, and different evidence quotes can still produce repeated venue cards.
- No high-concurrency capacity result, App Store release, or completed booking is claimed.
